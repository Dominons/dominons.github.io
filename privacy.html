Política de Privacidad de Dominon

Dominon es una aplicación web de productividad y análisis para usuarios técnicos.

1. Responsable y contacto

El responsable de Dominon es DANIFU777. Para consultas relacionadas con privacidad, datos personales o eliminación de información, puedes contactar al responsable mediante Discord: @DANIFU777.

2. Datos que recopilamos

Según las funciones que utilices, Dominon puede procesar:

  • Datos de autenticación de Google: nombre visible, dirección de correo electrónico, fotografía de perfil, identificador de usuario de Firebase y datos técnicos necesarios para mantener la sesión.
  • Contenido del bloc de notas: notas y páginas creadas dentro de la aplicación.
  • Contenido de Quantis: proyectos, páginas, dibujos, bloques, configuraciones del espacio de trabajo y archivos o imágenes que el usuario inserte voluntariamente.
  • Conversaciones de Gemini: mensajes enviados y respuestas recibidas mediante el asistente de IA.
  • Preferencias locales: tema, idioma, pestaña activa, configuración de interfaz, posición de algunos paneles y otros estados guardados en el almacenamiento del navegador.
  • Archivos locales: archivos de audio utilizados por el reproductor y archivos importados en notas o Quantis. Estos archivos se procesan localmente, salvo que una función de sincronización de la aplicación los incluya expresamente en los datos guardados.

3. Inicio de sesión con Google

Dominon utiliza Firebase Authentication con Google como proveedor de inicio de sesión. Google proporciona los datos básicos de la cuenta autorizados por el usuario, como nombre, correo electrónico, fotografía e identificador. Dominon utiliza esos datos para identificar la cuenta, mostrar la sesión activa y asociar los datos de la aplicación con el usuario correcto.

Dominon no solicita acceso a Gmail, Drive, Contactos ni a otros servicios de Google. El permiso utilizado corresponde al inicio de sesión y a la información básica de la cuenta.

4. Uso de Firestore y Firebase

Firebase y Cloud Firestore proporcionan autenticación, almacenamiento y sincronización de datos. En los planes que incluyen almacenamiento en la nube, Dominon guarda los datos asociados al identificador de Firebase del usuario, incluyendo notas, espacios de trabajo de Quantis y conversaciones de Gemini cuando corresponde.

Los datos se guardan bajo la cuenta autenticada y las reglas de seguridad del proyecto Firebase controlan el acceso. Las funciones disponibles pueden depender del plan de membresía del usuario.

5. Almacenamiento local

Dominon utiliza localStorage del navegador para conservar contenido y preferencias localmente. Esto permite que las notas, proyectos, conversaciones y configuraciones estén disponibles en el mismo navegador. El almacenamiento local puede eliminarse al borrar los datos del sitio, cambiar de navegador o utilizar otro dispositivo.

6. Asistente Gemini y API keys

El asistente Gemini es opcional. Para utilizarlo, el usuario puede introducir voluntariamente una API key de Google AI Studio. La aplicación la guarda localmente en el navegador asociada al usuario; no la guarda en Firestore. Cuando el usuario envía un mensaje, el texto de la conversación se envía a la API de Google Generative Language para generar una respuesta.

El tratamiento de esos datos por Google también está sujeto a las políticas y condiciones de Google. El usuario no debe introducir información sensible, confidencial o de terceros en el asistente.

7. Analytics y servicios externos

El proyecto inicializa Firebase Analytics. También puede cargar recursos o servicios externos como Google Fonts, Font Awesome, GSAP, TradingView, Firebase y Google Generative Language. Estos servicios pueden recibir datos técnicos de conexión conforme a sus propias políticas de privacidad.

El reproductor de música utiliza archivos locales seleccionados por el usuario y no sube automáticamente el audio a Dominon.

8. Finalidades

La información se utiliza para:

  • permitir el inicio de sesión y mantener la sesión activa;
  • asociar notas, proyectos y conversaciones con la cuenta correcta;
  • proporcionar sincronización en la nube cuando el plan lo permite;
  • mostrar y conservar preferencias de la aplicación;
  • proporcionar el asistente Gemini cuando el usuario lo activa;
  • mantener, proteger y mejorar el funcionamiento técnico de la aplicación.

9. Conservación y eliminación

Los datos locales permanecen en el navegador hasta que el usuario los elimina o borra los datos del sitio. Los datos sincronizados en Firestore permanecen mientras la cuenta y los registros correspondientes estén activos, salvo que el usuario solicite su eliminación o el responsable los elimine conforme a sus obligaciones aplicables.

Para solicitar la eliminación de datos asociados a una cuenta, contacta al responsable mediante Discord: @DANIFU777. También puedes cerrar sesión y eliminar los datos locales desde la configuración del navegador.

10. Seguridad

Dominon utiliza Firebase Authentication, reglas de seguridad de Firebase y Firebase App Check como medidas de protección. Ningún sistema conectado a Internet puede garantizar seguridad absoluta; el usuario debe proteger su cuenta y no compartir sus credenciales ni API keys.

11. Cambios en esta política

Esta política puede actualizarse para reflejar cambios en Dominon, sus servicios o los requisitos legales. La versión publicada en esta página será la versión vigente.
